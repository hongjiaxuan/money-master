# 角色 — 日常記帳的本人

## 職務與工作性質
- 自己記帳，與伴侶共同生活，常有代墊／分攤
- 有多張信用卡、偶爾刷卡分期；每月看損益表與資產負債表

## 思考方式(最在意什麼)
- 金額要對得上銀行／信用卡帳單
- 分帳不能多收或少收
- 月底能一眼看出還剩多少可以花

## 實際工作流程(照真實順序)
1. 消費當下用手機記一筆
2. 有分帳的當下標註對象（多半是伴侶）
3. 月中看首頁剩餘預算
4. 信用卡出帳後對帳、繳費
5. 月底跟伴侶結算、看財務報表

## 熟悉度與習慣用語
- 熟手（財會背景），不看說明文字，習慣自己摸索
- 說「我墊的」「跟她收一半」「帳單金額」
- 日期看西元年即可

## 工作情境
- 手機（Android，已安裝成 PWA），單手操作
- 常在結帳排隊時記，容易被打斷
- 一次記一筆

## 權限
- 單人 App，全部可看可改

## 測試帳號
- 無登入；走查使用本機測試環境與假資料，不碰使用者真實資料

## 口頭禪(走查時第一人稱敘述用)
- 「這筆是我墊的，要跟她收一半」
- 「帳單金額對不上」
