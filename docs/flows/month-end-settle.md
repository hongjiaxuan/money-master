## 前置條件
- 本月與伴侶有三筆未結清：我墊分攤 900（信用卡）、伴侶先付的日用品 600（他墊）、幫伴侶代購 300（現金）
- 帳戶：現金 4,520、銀行 50,000、信用卡 -2,100

## 步驟
1. 進分帳頁，看本月要跟伴侶結算多少 → 預期結果：一眼看出「伴侶應付我 $450」（450＋300－300）
2. 全選後按「結算」 → 預期結果：結算視窗預設金額 450，看得懂怎麼算出來的
3. 匯出結算明細圖片傳給伴侶 → 預期結果：圖片逐筆列出、合計與結算金額一致
4. 選收款帳戶（銀行），確認收款 → 預期結果：有成功回饋
5. 核對結果 → 預期結果：分帳清單清空、銀行 +450、歷史抽屜有這一批、可反結算
