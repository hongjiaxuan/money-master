## 前置條件
- 已有帳戶（現金、信用卡）、預設分類、分帳對象「伴侶」
- 本月已有幾筆一般支出

## 步驟
1. 首頁點「＋」開始記帳 → 預期結果：出現分類選單
2. 選分類（餐飲） → 預期結果：進入分帳方式選擇
3. 選「一起分攤」並指定伴侶、選信用卡扣款 → 預期結果：進入金額頁，看得到分攤對象
4. 輸入 900、備註「晚餐-走查」並存檔 → 預期結果：有成功回饋，首頁清單出現該筆，月支出只算我的 450
5. 到分帳頁確認 → 預期結果：伴侶分頁出現該筆，應收 450
